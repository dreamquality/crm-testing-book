# CRM Testing Book

A comprehensive guide with practical test assignments for QA engineers focusing on the [Employee Management CRM](https://github.com/dreamquality/employee-management-crm) system.

## 📚 About This Book

This book contains hands-on testing assignments designed to develop and assess QA skills across multiple domains including manual testing, API testing, UI automation, and containerized application testing.

## 🎯 Target Audience

- QA Engineers
- Test Automation Engineers
- Software Testers looking to enhance their skills
- DevOps engineers interested in testing practices

## 📖 Chapters

Each chapter represents a complete testing assignment with clear objectives, instructions, and deliverables.

### [Chapter 1: Testing a Dockerized Web App](./chapter-01-testing-dockerized-web-app.md)

**Focus:** Comprehensive testing of a containerized Employee Management CRM application

**Testing Guides:**
- **[Manual Testing](./manual-testing.md)** - Test plan creation, execution, and bug reporting
- **[API Automation](./api-automation.md)** - Automated API testing with Postman
- **[UI Automation](./ui-automation.md)** - Automated UI testing with Cypress or Playwright

**Skills Covered:**
- Docker containerization and deployment
- Manual testing and exploratory testing
- API automation with Postman
- UI automation with Cypress/Playwright
- Test report documentation

**What You'll Learn:**
- How to launch and test Dockerized applications
- Manual and automated testing approaches
- API and UI testing best practices
- Professional test documentation

## 🚀 Getting Started

1. Choose a chapter/assignment
2. Read through the complete assignment description
3. Set up the required tools and environment
4. Complete the assignment stages
5. Submit your deliverables as specified

## 🛠️ Common Tools & Prerequisites

- **Docker & Docker Compose** - For running containerized applications
- **Postman** - For API testing
- **Cypress or Playwright** - For UI test automation
- **Git** - For version control
- Basic knowledge of HTTP, REST APIs, and web technologies

## 📝 Assignment Submission

Each assignment specifies what needs to be submitted. Generally, this includes:
- Test reports (manual and automated)
- Test automation code
- Test execution results
- Bug reports (if applicable)
